# UI Accessibility Checklist

Scope: `ui/src` chat UI. Target: WCAG 2.2 AA in both light and dark themes.

## Keyboard / focus order
- [x] Logical DOM order: sidebar (new chat, history) → top bar (language, developer view, theme) →
  conversation (`main#chat-log`) → composer. No positive `tabindex`.
- [x] Skip link ("Skip to conversation") is visually hidden until focused (`.skip-link`).
- [x] All actions are native `<button>`/`<input>`/`<textarea>`/`<form>`; no div click handlers.
- [x] Feedback thumbs are grouped (`role="group"`, `aria-label="Rate this answer"`) with
  `aria-pressed` and per-button labels. They are hidden on busy/offline replies, where rating
  has no meaning.
- [x] Citation markers are real `<button>`s with `aria-label="Source n"`; the source chips under
  each answer are a labelled list of buttons; Escape closes the source panel and the menus.
- [x] Starter questions on the empty screen are buttons in a labelled list (all six on phones).

## Visible focus
- [x] Global `:focus-visible` rule: 2px accent outline + 2px offset (`--focus-ring`).
- [x] The composer shows an accent border and ring while focused; no `outline: none` without a
  replacement.

## Contrast (WCAG AA, measured against the flat surface each token sits on)

| Token | Light | Dark |
|---|---|---|
| `--text-main` on canvas | 17.7:1 | 18.1:1 |
| `--text-muted` on canvas | 4.8:1 | 7.8:1 |
| `--text-dim` on sidebar (history label, footer, placeholders) | 4.7:1 | 5.4:1 |
| `--accent-text` on canvas (starter labels, links, list numbers) | 5.5:1 | 10.3:1 |
| Citation badge text on its fill | 5.2:1 | 9.0:1 |
| Notice text on the "couldn't verify" fill | 9.9:1 | 12.0:1 |

`--accent-green` (`#059669`) is only used for fills, borders and icons; small green text uses
`--accent-text`, which is darker in light mode.

## Names / labels / live regions
- [x] Both composers (hero `<textarea>`, chat `<input>`) have an sr-only `<label>`.
- [x] Hindi text carries `lang="hi"` (answers with `lang: "hi"`, user messages and starters in
  Devanagari) so screen readers switch voice.
- [x] Chat log is `role="log"` with `aria-live="polite"`; new answers announce without moving focus.
- [x] The loading row is `role="status"` and its stage text ("Searching BIS sources…") is announced.
- [x] Errors use `role="alert"`; toasts use `role="status"`.
- [x] Language menu is `role="menu"` with `menuitemradio` items and `aria-checked`.
- [x] Decorative bullets and icons are `aria-hidden`.

## Theme / motion / layout
- [x] Theme follows the system preference until the user picks one, then remembers it; it is applied
  in `index.html` before first paint, and `color-scheme` makes native scrollbars match.
- [x] `prefers-reduced-motion: reduce` turns off entrance animations, shimmer and pulse.
- [x] No horizontal scroll at 390px; the mobile sidebar is a drawer with a backdrop.

## Hindi QA
- [x] `chat-hindi.json` is a recorded Hindi answer; the contract test asserts Devanagari
  `[ऀ-ॿ]` and `lang: "hi"`.
- [x] Font stack includes `"Noto Sans Devanagari"`.
