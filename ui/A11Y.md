# UI Accessibility Checklist (Phase 5 a11y pass, plan §5)

Scope: `ui/src` chat console. Target: WCAG 2.2 AA for a test console
used by non-technical BIS reviewers.

## Keyboard / focus order
- [x] Logical DOM order: header → view nav → samples → conversation (`main#chat-log`) → composer footer.
  No positive `tabindex`; the log region is `tabIndex={-1}` so skip-link focus works without entering tab order.
- [x] Skip link (“Skip to conversation”) visually hidden until focused (`App.tsx`, `.skip`).
- [x] All actions are native `<button>`/`<input>`/`<select>`/`<form>` — no div-click handlers.
- [x] Feedback thumbs are grouped (`role="group"`, `aria-label="Rate this answer"`) with `aria-pressed`
  state and per-button `aria-label`s; reachable and operable via Tab + Enter/Space.
- [x] Citation markers `[n]` are real `<button>`s with `aria-label="Source n"`; the numbered source
  chips below each answer are a labelled list of buttons, and Escape closes the source panel.
- [x] Starter questions on the empty screen are buttons in a labelled list.

## Visible focus
- [x] Global `:focus-visible` rule: 3px `#0b5fff` outline + 2px offset (`styles.css`).
- [x] Skip link appears on focus; never `outline: none` without a replacement.

## Contrast (WCAG AA, checked against flat backgrounds)
- [x] Body text `#16283c` on `#f4f6f9` / `#fff` — ~14:1.
- [x] Muted text darkened to `#42546a` on `#f4f6f9` — ≈7:1 (was `#5b6b7d`, lightened risk on small text).
- [x] Badges: ok `#14532d`/`#dff2e2`, refuse `#713f12`/`#fef3c7`, lang `#312e81`/`#e0e7ff`,
  pii `#7f1d1d`/`#fde2e2`, known chips `#123a63`/`#eef6ff`, assumption banner `#422006`/`#fff8e6` —
  all ≥4.5:1 for 11–12px text.
- [x] Composer + inputs keep 1px `#dfe6ee` borders on white with dark text; ghost buttons use
  `#42546a` text (not the old lighter `#5b6b7d`).

## Names / labels / live regions
- [x] Language `<select>` (Auto/EN/हिंदी) and chat `<input>` have associated `<label className="sr-only">` + `aria-label`.
- [x] Chat input sets `lang="hi"` when Hindi is picked so screen readers/IMEs switch correctly; assistant bubbles carry `lang="hi"` when answered in Hindi.
- [x] Health pill, feedback confirmation, admin status, and export note use `role="status"`. The status dot itself is `aria-hidden`; state is announced once via an adjacent sr-only status node (never color-only).
- [x] Chat log is `role="log"` with `aria-live="polite"` so new answers announce without moving focus.
- [x] Assumptions banner uses `role="note"` + `aria-label`; known chips list has an accessible label.
- [x] Decorative bullets (`•`) and emoji qualifiers are `aria-hidden` or paired with `.sr-only` text.
- [x] `index.html` has `lang="en"` + meta description; Hindi content is per-element via the input/rendered text.

## Motion / layout
- [x] `prefers-reduced-motion: reduce` disables smooth scrolling/transitions.
- [x] Admin table scrolls horizontally (`.tablewrap`) instead of breaking at 320px widths.

## Hindi QA (plan §5)
